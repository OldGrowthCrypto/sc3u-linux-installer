# Contributing

Thanks for helping keep SimCity 3000 Unlimited alive on Linux.

* Report bugs and ideas in [Issues](https://github.com/OldGrowthCrypto/sc3u-linux-installer/issues). Include your distro, desktop (Wayland or X11), GPU and `~/.loki/sc3u/last-run.log`.
* Pull requests are welcome. Keep changes small and focused, and run `python3 -m unittest discover -s tests` before sending.
* Never commit game data from the disc or ISO.
* By contributing you agree your code is licensed GPL-3.0-or-later.
